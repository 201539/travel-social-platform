## 试题要求

- 输入：第一行一个整数 `n`，表示区间个数。接下来 `n` 行/个字符串，每个为时间段，格式为 `HH:MM-HH:MM`。
- 任务：最少删除多少个区间，使剩余的时间段两两不重叠。
- 输出：一个整数，表示需要删除的最小区间数量。

思路提示：按照结束时间从早到晚排序，尽量“选择”结束时间最早且不与当前已选择区间冲突的区间。每遇到与当前选择冲突的区间，相当于“删除”它，累加删除次数。

## 源码与逐行注释（面向初学者）

```cpp
#include <iostream>          // 标准输入输出（cin/cout）
#include <vector>            // 动态数组容器 vector
#include <string>            // 字符串类型 std::string
#include <algorithm>         // 常用算法（如 sort）

using namespace std;         // 简化书写：允许直接写 cout、vector 等（入门可用）

int timeToMinutes(const string &time) {             // 将 "HH:MM" 转为自 00:00 起的分钟数
    int hours = stoi(time.substr(0, 2));            // 截取前 2 位（小时）并转换为整数
    int mimutes = stoi(time.substr(3, 2));          // 从下标 3 起取 2 位（分钟），注意冒号位于下标 2
    return hours * 60 + mimutes;                    // 总分钟 = 小时×60 + 分钟
}

int main() {                                        // 程序入口
    int n;                                          // 读取区间数量 n
    cin >> n;                                       // 从标准输入读入 n
    vector<string> intervals(n);                    // 存放原始区间字符串，如 "09:00-10:30"
    for (int i = 0; i < n; ++i) {                   // 读入每个区间字符串
        cin >> intervals[i];                        // 假定输入格式严格为 HH:MM-HH:MM
    }

    vector<pair<int, int>> parsedIntervals;         // 存放解析后的区间：以分钟为单位的 [start, end)

    for (const string &s : intervals) {             // 遍历每个区间字符串
        int start = timeToMinutes(s.substr(0, 5));  // 起始时间：从 0 截取 5 个字符（HH:MM）再转分钟
        int end = timeToMinutes(s.substr(6, 5));    // 结束时间：跳过 '-'（下标 5），从 6 截取 5 个字符
        parsedIntervals.push_back({start, end});    // 压入转换后的区间
    }

    sort(parsedIntervals.begin(), parsedIntervals.end(),            // 对区间按结束时间升序排序
         [](const pair<int, int> &a, const pair<int, int> &b) {
             return a.second < b.second;                            // 结束早的排在前面（贪心关键）
         });

    int endTime = -1, count = 0;                    // endTime：已选最后区间的结束；count：需要删除的个数

    for (auto &interval : parsedIntervals) {        // 依次考察结束时间从早到晚的区间
        if (endTime <= interval.first) {            // 若当前区间的开始 >= 已选结束 → 不重叠
            endTime = interval.second;              // “选择”该区间：更新当前结束时间
        } else                                      // 否则发生重叠（与当前已选的最后一个区间）
            count++;                                // 按“最少删除”计数：删除当前这个区间
    }

    cout << count << endl;                          // 输出最少需要删除的区间个数

    return 0;                                       // 程序正常结束
}
```

- `#include <iostream>`：引入标准输入输出库，提供 `cin`、`cout`。
- `#include <vector>`：引入动态数组容器 `vector`。
- `#include <string>`：引入字符串类型 `std::string`。
- `#include <algorithm>`：引入通用算法，如 `sort`。
- `using namespace std;`：将 `std::` 命名空间引入当前作用域，初学时便于书写（正式项目更建议显式写 `std::` 以避免命名冲突）。

- `int timeToMinutes(const string &time)`：定义函数，将形如 `HH:MM` 的时间转换为自 00:00 起的总分钟数。
  - `const string &time`：常量引用传参，避免拷贝、更高效且不修改实参。
  - `time.substr(0, 2)`：从位置 0 起取长度为 2 的子串（小时）。
  - `time.substr(3, 2)`：从位置 3 起取长度为 2 的子串（分钟），位置 2 是冒号 `:`。
  - `stoi(...)`：将字符串转换为整数。
  - 变量名 `mimutes` 拼写上是个小瑕疵（应为 `minutes`），但不影响程序运行。
  - `return hours * 60 + mimutes;`：总分钟数 = 小时×60 + 分钟。

- `int main()`：主函数，程序入口。
  - 声明 `int n;` 并读取：`cin >> n;`。
  - `vector<string> intervals(n);`：创建长度为 `n` 的字符串数组用于存放原始区间，如 `"09:00-10:30"`。
  - `for (int i = 0; i < n; ++i) cin >> intervals[i];`：逐个读入。

- `vector<pair<int, int>> parsedIntervals;`：用于存放解析后的区间，转为以分钟计的 `(start, end)`。
  - `for (const string &s : intervals)`：范围 for 遍历每个原始字符串。
    - `s.substr(0, 5)`：取起始时间段 `HH:MM`。
    - `s.substr(6, 5)`：跳过中间的 `-`，取结束时间段 `HH:MM`。
    - `timeToMinutes(...)`：转换为整数分钟。
    - `parsedIntervals.push_back({start, end});`：压入区间。

- `sort(parsedIntervals.begin(), parsedIntervals.end(), [](const pair<int,int>& a, const pair<int,int>& b){ return a.second < b.second; });`
  - 使用 `sort` 并提供一个 Lambda 比较器。
  - `[](const pair<int,int>& a, const pair<int,int>& b)`：匿名函数，按 `end`（第二个元素）从小到大排序。
  - 贪心思想：优先“保留”结束更早的区间，能给后续区间留下更大可用空间。

- `int endTime = -1, count = 0;`：`endTime` 记录当前已选择的最后一个区间的结束时间；`count` 统计需要删除的区间数。
  - 初始为 `-1` 保证第一个区间一定可以被选择（任意非负起点均 ≥ -1）。

- 遍历排序后的区间：`for (auto &interval : parsedIntervals)`。
  - `if (endTime <= interval.first)`：若当前区间的开始时间不早于已选择区间的结束时间，则不重叠，更新 `endTime` 为当前区间的结束时间，即“选择”它。
  - `else count++;`：否则与已选择的区间重叠，按题意我们“删除”它，删除数加一。

- `cout << count << endl;`：输出最少删除的区间数量。
- `return 0;`：正常结束。

### 复杂度分析
- 排序复杂度：\( O(n \log n) \)
- 一次线性遍历计数：\( O(n) \)
- 总体：\( O(n \log n) \)

### 易错点与改进建议
- 输入格式必须严格为 `HH:MM-HH:MM`，否则 `substr` 截取位置会出错。
- 变量拼写 `mimutes` 建议改为 `minutes`，提高可读性。
- 可以在解析时增加合法性校验（小时 0–23，分钟 0–59）。
