## 试题要求

- 实现一个模板动态数组 `ArrayList<T>`，支持：
  - 添加元素 `add`
  - 删除指定元素 `remove`
  - 按下标访问 `get`（越界时返回空）
  - 查询当前 `size` 与底层 `capacity`
- 要求自行管理内存并支持自动扩容。

---

## 源码与逐行注释（面向初学者）

```cpp
#include <iostream>                 // 标准 I/O（常用于测试）
#include <optional>                 // std::optional：可空返回值容器

using std::optional;               // 引入名称，书写更简洁

template <typename T>              // 模板：支持任意类型 T
class ArrayList {                   // 动态数组类：提供自动扩容
private:                            // 私有成员：仅类内可访问
    T *array;                       // 底层连续存储区（原始指针）
    int size;                       // 实际元素个数
    int capacity;                   // 分配的容量（最多能容纳的元素数）

    // 扩容
    void resize() {                 // 当空间不足时，将容量扩大为 1.5 倍
        capacity = capacity + (capacity / 2);   // 新容量 = 旧容量 + 旧容量/2
        T *newArray = new T[capacity];          // 申请更大的连续空间
        for (int i = 0; i < size; ++i)          // 逐个拷贝旧数据到新空间
            newArray[i] = array[i];

        delete[] array;                         // 释放旧空间，避免内存泄漏
        array = newArray;                       // 指向新空间
    }

public:                             // 公有接口：外部可调用
    ArrayList() : size(0), capacity(10) {       // 构造：初始 size=0, capacity=10
        array = new T[capacity];                // 根据容量分配底层数组
    }

    void add(T &x) {                            // 尾部添加一个元素（按值拷贝）
        if (size >= capacity)                   // 若空间不足
            resize();                           // 先扩容
        array[size++] = x;                      // 复制到末尾位置，然后 size 自增
    }

    void remove(T &x) {                         // 删除第一个等于 x 的元素
        for (int i = 0; i < size; ++i) {        // 线性查找（要求 T 支持 ==）
            if (array[i] == x) {                // 找到匹配元素
                for (int j = i; j < size - 1; ++j)
                    array[j] = array[j + 1];    // 将后续元素整体左移覆盖
                --size;                          // 元素个数减一
                return;                          // 只删第一个，随后返回
            }
        }
    }

    optional<T> get(int x) {                    // 按下标访问：可能越界
        if (x < 0 || x >= size)                 // 越界检查
            return std::nullopt;                // 越界时返回“空值”

        return array[x];                        // 否则返回该位置元素的拷贝
    }

    int getSize() {                             // 返回当前元素个数
        return size;
    }

    int getCapacity() {                         // 返回当前容量
        return capacity;
    }
};
```

- `#include <iostream>`：引入标准 I/O（本类未直接使用，但常用于测试）。
- `#include <optional>`：引入 `std::optional`，用于可能“无值”的返回场景。
- `using std::optional;`：将 `optional` 引入当前作用域，使用时可写成 `optional<T>`。

- `template <typename T>`：模板声明，使容器可存放任意类型 `T`。
- `class ArrayList { ... }`：定义泛型动态数组。
  - `private:` 成员仅类内可访问。
    - `T *array;`：指向底层连续存储的原始指针。
    - `int size;`：当前已存元素个数。
    - `int capacity;`：当前底层数组容量（最多可容纳元素数）。
  - `void resize()`：扩容策略与拷贝迁移。
    - `capacity = capacity + (capacity / 2);`：容量变为原来的 1.5 倍。
    - `new T[capacity]`：分配更大的连续空间。
    - `for (...) newArray[i] = array[i];`：逐个拷贝旧数据到新空间。
    - `delete[] array; array = newArray;`：释放旧空间，并更新指针。

- `public:` 公有接口。
  - `ArrayList() : size(0), capacity(10) { array = new T[capacity]; }`：
    - 使用成员初始化列表将 `size` 置 0，`capacity` 初始为 10。
    - 根据初始容量分配底层数组。
  - `void add(T &x)`：尾部插入元素。
    - 若 `size >= capacity` 先扩容。
    - `array[size++] = x;`：将元素拷贝到尾部位置，再递增 `size`。
    - 语法说明：`size++` 是后缀自增，先用后加一。
  - `void remove(T &x)`：删除与 `x` 相等的第一个元素。
    - 线性查找相等元素（要求 `T` 支持 `==`）。
    - 找到后将后续元素整体左移一格，并 `--size`。
    - 未找到则不作处理。
  - `optional<T> get(int x)`：按下标访问。
    - 越界 (`x < 0 || x >= size`) 返回 `std::nullopt` 表示“没有值”。
    - 否则返回 `array[x]` 的一个拷贝（`optional<T>` 内含该值）。
  - `int getSize()` / `int getCapacity()`：分别返回当前元素数量与容量。

### 使用示例
```cpp
ArrayList<int> a;
int v1 = 3, v2 = 5;
a.add(v1);
a.add(v2);
auto t = a.get(1);      // 有值：5
auto bad = a.get(10);   // 无值：std::nullopt
```

### 复杂度与特性
- `add`：均摊 \( O(1) \)（偶尔触发扩容时为 \( O(n) \) 拷贝）。
- `remove`：最坏 \( O(n) \)（线性查找 + 左移）。
- `get`：\( O(1) \) 随机访问。

### 易错点与改进建议
- 资源管理：当前类缺少析构函数，存在内存泄漏风险；建议实现“规则五/三”中的：
  - 析构函数 `~ArrayList()` 释放 `array`。
  - 拷贝构造、拷贝赋值、移动构造、移动赋值，确保拷贝/转移语义正确。
- 接口签名：
  - `add`/`remove` 的参数应为 `const T&`，避免对实参的非必要修改并允许绑定右值/临时量。
  - `get`、`getSize`、`getCapacity` 应加 `const` 限定（如 `int getSize() const`）。
- 异常安全：`new` 失败或拷贝构造抛异常时需要更健壮的处理。
- 泛型约束：使用 `==` 要求 `T` 可比较，必要时可改为传比较器模板参数。
